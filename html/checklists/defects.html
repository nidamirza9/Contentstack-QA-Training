Defect taxonomy — Contentstack QA

Classify every bug before you file it. Wrong layer = wrong owner and wasted time.

---

Layers

CodeLayerOwner (typical)Evidence required
ACMS authoring / workflow / roles / assetsEditor, CMS adminEntry UID, stage, permissions screenshot
BDelivery / Preview / Release contractFrontend (query) or CMS admin (publish)CDA/Preview JSON, env, locale, token type
CApp render / cache / routing / formatFrontend, DevOpsHAR or URL + JSON proving field exists

A ticket may list a primary layer and a secondary (example: A unpublished ref causing B empty include).
