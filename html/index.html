How QA on Contentstack is different

Editors type in Contentstack. The website is a separate app that fetches JSON. A perfect CMS screen can still fail on the live site.

Recommended path

  1. CMS screens (labeled) — learn the real UI first
  2. Training summary — 30–40 minutes
  3. Modules 01–05 — about 1 day
  4. Labs 00–08 on a trial stack — 2–3 days
  5. Checklists on the first client project
  6. Component / template QA issues — use during template UAT
